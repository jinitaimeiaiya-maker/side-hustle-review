# 我把副业网站挨个注册了一遍，只有一个不用先交钱

过去两个月，我把能在中文互联网上搜到的副业网站挨个注册了一遍。

不是为了找个项目做，是为了验证一件事：**到底有没有一个不用先掏钱的。**

结论有点扫兴：我注册了十几个，绝大多数在第三步之前就会问你要钱。只有一个从注册走到第一笔结算，全程没让我付过一分钱。

这份记录就是把这个筛选过程摊开写，包括我淘汰每一个的理由。你可以照着我这套标准自己去测一遍，不用信我说的。

---

## 先说我想要什么样的

很具体，就四条，按顺序过，任何一条不过就出局：

| 条件 | 为什么 |
|---|---|
| 注册后不交任何费用 | 入门费、培训费、保证金、软件费，换个名字都算 |
| 收益不依赖拉人 | 需要发展下线的结构，数学上必然是零和，后进的人亏 |
| 不用真人出镜 | 不拍视频、不直播、不露脸 |
| 收款不经过我 | 要垫付、要代收、要押款的，一律排除 |

第 1 条砍掉一大半，第 4 条再砍掉一半。四条全过之后，剩下的通常不到一个。

第 4 条很多人不理解，我多说一句：**只要钱要经过你的手，你的风险性质就变了。** 垫付的钱收不回来是小事，万一被卷进纠纷，性质就不一样了。所以我从一开始就只找“别人直接付给平台、平台给我结算”的模式。

## 被淘汰的那些，卡在哪

不点名具体公司，因为大部分是同类套路，点名意义不大。按失败原因归类：

### 一、注册就要交入门费（最多的一类）

话术通常是“99 元开通推广权限”“199 元成为分销商”“3000 元起步货款”。

共同点：这笔钱交完之后，你拿到的不是收入，是**资格**。而资格能不能变现，取决于你能不能卖出去，跟交没交钱没关系。

判断方式很简单：**问一句“我不交钱能不能先看看有什么”，对方如果绕，直接关掉。**

### 二、收益靠拉人

典型结构是“邀请 3 人解锁提现”“团队业绩达到多少返点”。

这类东西不管包装成会员、代理还是合伙人，底层都是资金的向上集中。**它的数学决定了：先来的赚后来了，总盘子不增加。** 你赚的每一分都是另一个人的本金。

我不是说这一定违法，我是说这跟“劳动换收益”是两件事。

### 三、必须真人出镜

拍视频、开直播、真人语音，每天有固定时长要求。

这类我不评价好坏，只是不适合我——我不想让同事刷到，也不想把下班时间绑在镜头前。如果你本来就在做内容，这条对你不算门槛。

### 四、灰产和擦边

刷单、任务墙、代实名、跑分。碰都不要碰，不用展开。

## 唯一留下来的那个

它属于**推广分佣**这一类，逻辑非常朴素：

平台有一个产品，你分享带自己标识的入口，有人通过你的入口付费，平台把差价结算给你。

我把它拿出来单独写，是因为它同时过了上面四条，而且过得很干净：

- **注册免费**，走到结算没让我付过任何费用
- **不需要拉人**，有一个人通过你的入口付费，就结算一次，跟下线没关系
- **不需要露脸**，全流程没有出镜、没有语音、没有直播要求
- **收款不经过你**，用户直接付给平台，你拿差价。你不用垫钱，不用代收，也不用向朋友开口要钱

最后这条是决定性的。前面那些失败的项目，本质上都要你承担“收钱”这个动作，而这个动作一旦发生，你和朋友的关系就变味了。这个模式把这一步切掉了。

### 但它有很明显的缺点

我不能只写好的，那样你会觉得我在骗你。

**第一，收入完全取决于触达人数。** 没有人看到你的入口，收入就是零。它不承诺任何保底，也没有“努力就有回报”这种话。这是个纯流量生意。

**第二，天花板很低。** 它不是能让生活发生变化的收入。我把它定位成“多条链路里的第一条”，不是救命稻草。

**第三，前期几乎看不到反馈。** 我第一个月的数据很难看，具体多难看后面写。

### 我自己现在什么情况

老实说：**还没跑通。**

我目前推出去的人里，走到“真正注册成功”这个动作的是零。点进来看的人有，但停在注册页之前。

所以你现在看到的不是一个成功案例，是一个正在进行的测试。我写这份东西的时候，也没法告诉你“照做能赚多少”，因为我自己还不知道。

我能确定的只有一件事：**我花的钱是零，花的时间是几个晚上。** 这个成本我赔得起，赔了也不心疼。这是我选它的唯一理由。

## 你可以照这个流程自己测

不要信任何人的推荐，包括我这份。自己花一个晚上过一遍：

1. **先注册，不要付任何钱。** 任何一步要求付费，直接退出，不用听解释。
2. **找到它的结算规则页面**，看清楚“什么条件下才结算”。如果规则里出现“团队”“层级”“发展”这类词，停。
3. **走一遍完整流程**：自己扫自己的码、自己付费、自己看有没有到账。流程不通，后面全是白费。
4. **算清楚最坏结果。** 把最坏情况写在纸上，如果写着写着心里发慌，那就别做。

第 3 步最容易被跳过，但它最有用——**你自己都走不通的流程，指望别人走通是不现实的。**
